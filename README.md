# Donko Partituras 🎵

Sitio web público para compartir y consultar partituras en formato PDF.

## Stack
- **Framework:** Astro (Static Output) + React Islands
- **Estilos:** Tailwind CSS
- **Lenguaje:** TypeScript (Strict)
- **Backend / Storage:** Supabase (RLS habilitado)
- **Hosting:** Cloudflare Pages

## Desarrollo
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build
```
